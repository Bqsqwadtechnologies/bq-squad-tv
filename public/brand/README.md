This is the upload location for the official BQ SQWAD TV brand artwork.

## Replace the current logo

Upload the approved logo to this folder using this exact filename:

`bq-sqwad-tv-logo.svg`

The website already references it at `/brand/bq-sqwad-tv-logo.svg`. Replace that file to update the website logo without changing application code.

For Android, provide a transparent PNG version of the same approved artwork named:

`bq_sqwad_tv_mark.png`

Place it in `android/app/src/main/res/drawable-nodpi/`. The Android app currently uses the vector mark at `android/app/src/main/res/drawable/bq_sqwad_tv_mark.xml`; when the approved PNG is supplied, update the app's image references to use the approved asset and remove the temporary mark only after verifying the new asset builds.

Use a transparent background where possible. Keep the original proportions; do not stretch or recolor the approved logo.
